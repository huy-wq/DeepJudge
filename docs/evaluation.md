# 评测与实验设计

> 目的：让"评判效果好不好"成为**可量化、可复现、可对比**的结论，而不是演示几个案例。
> 答辩时最容易被问的两句是"你怎么证明它准"和"它和老师差多少"——本文档就是答案。

## 1. 研究假设

| 编号 | 假设 | 验证方式 |
| --- | --- | --- |
| H1 | 采分点结构化评分比"直接打分"一致性更高 | 对比 B0/B1 与 B2 的 QWK、重复测量标准差 |
| H2 | 证据接地校验能显著降低幻觉判分 | grounding rate、人工抽检编造率 |
| H3 | 多采样聚合 + 校准能缩小与教师评分的差距 | 校准前后 MAE/QWK |
| H4 | 思考强度提升能改善复杂题（论述/案例）表现，但对简单题性价比低 | 模型档位 × effort 三档 × 题型分层（档位待定） |

## 2. 数据集

### 2.1 来源与分层

- 来源：本校课程真实试题与答卷（脱敏授权）＋ 公开数据集补充。
- 题型分层（每层不少于 60 条）：简答、论述、案例分析、计算过程（含步骤分）、编程题。
- 每题配 1 份权威评分标准，转换为 3.2 节的 rubric schema。

### 2.2 标注规范

- **双人独立评分 + 第三人仲裁**（分歧 > 满分 10% 时触发）。
- 标注粒度：总分 + **逐采分点命中情况**（这是训练校准与评估 grounding 的前提）。
- 标注前做校准培训（用 5 份样例统一尺度），记录标注者间一致性作为**人类上限**。

### 2.3 规模与划分

| 用途 | 规模 | 说明 |
| --- | --- | --- |
| 开发/调试 | 30~50 条 | 调 prompt、调 schema，可反复看 |
| 校准集 | 300~500 条 | 只用于拟合校准映射与选阈值 |
| 测试集 | 150~200 条 | **全程不参与任何调参**，只报一次 |
| 稳定性测试 | 30 条 × 10 轮重复 | test-retest |

划分按**题目**分层，同一题目的不同答案不能跨集合，避免泄漏。

## 3. 指标体系

分五层，每层 2~4 个指标，避免堆砌。

### 3.1 准确性（与人工分的一致性）

| 指标 | 含义 | 备注 |
| --- | --- | --- |
| **QWK**（二次加权 Kappa） | 与人工评分的一致性，教育测量领域标准指标 | 主指标；对"差 1 分"惩罚小于"差 3 分" |
| MAE / RMSE | 平均绝对误差 / 均方根误差 | 直观，便于答辩解释 |
| Pearson / Spearman | 线性/秩相关 | 看整体趋势 |
| 极端误差率 | `|Δ| ≥ 2` 的样本占比 | 比平均值更能反映"灾难性错误" |

QWK 计算前需把连续分按 0.5 或 1 分粒度离散化，离散粒度要在论文中写明。

### 3.2 一致性（重复评分稳定性）

- **ICC(2,1)**：同一答案多次评分的组内相关系数。
- 总分标准差（R=10 轮）。
- 逐采分点一致率：n 次采样中 level 完全相同的比例。

### 3.3 可解释性与可靠性

- **grounding rate**：通过证据定位校验的判定占比（核心创新指标）。
- 编造率：人工抽检 100 条判定，统计证据与原文不符的比例。
- schema 合规率、重试率、空响应率。

### 3.4 效率与成本

- 单份评分平均时延（P50/P95）。
- 单份 token 与费用（区分缓存命中/未命中）。
- **自动通过率**（无需人工的比例）与"自动通过样本中的人机一致率"——这两个数一起看才有意义，只报通过率是耍流氓。

### 3.5 教学价值（可选加分项）

- 诊断信息准确率：系统指出的"未掌握知识点"与教师判断的一致率。
- 分数分布合理性：与人工分布的形状对比（KS 检验）。

## 4. 基线与消融

| 编号 | 配置 | 验证 |
| --- | --- | --- |
| B0 | 零样本：只给题目 + 参考答案，让模型直接给分 | 最朴素基线 |
| B1 | 自然语言评分标准整段塞入，直接给总分 | 常见"提示词工程"做法 |
| B2 | rubric 结构化，逐采分点判定，**不做**证据校验 | H1 |
| B3 | B2 + 证据接地校验 | H2 |
| B4 | B3 + 多采样（n=3）聚合 | H3 前半 |
| B5 | B4 + 分数校准 + 阈值路由 | H3 后半（完整系统） |

独立变量：

- 模型档位：待接入后确定（至少两档，用于成本-性能对比）
- 采样参数：以实际 API 支持为准（若模型忽略 `temperature`，需在论文中说明稳定性从何而来）
- few-shot：0 / 2 / 5 条
- 采样次数：1 / 3 / 5

## 5. 统计检验

- 所有主指标给 **bootstrap 95% 置信区间**（1000 次重采样）。
- 配置间比较用**配对 Wilcoxon 符号秩检验**（同一批样本），报告效应量（Cliff's delta 或 Cohen's d）。
- 多组比较用 Holm 校正，避免 p-hacking。
- 明确报告样本量；不显著的差异不要写成"提升"。

## 6. 人类基线

教师之间的 QWK / MAE 是本课题的**理论参照系**：如果人机一致性接近或达到人际一致性，就足以支撑"可用于辅助评分"的结论。
这一栏几乎必然会被问到，务必提前算好。

## 8. 伦理与合规

- 答卷脱敏后方可进入模型调用；不向第三方传输可识别个人信息。
- 学生知情同意与数据用途说明；提供退出机制。
- 自动评分结果**仅作辅助**，最终成绩由教师确认（系统中保留人工终审权）。
- 审计日志保存调用与复核记录，支持追溯。

## 9. 可复现性

- 每次实验固定：rubric 版本、prompt 版本、模型名、参数、采样次数、随机性来源。
- 采样本身有随机性 → 报告时给出多次运行的均值与区间，而不是单次结果。
- 实验脚本与结果表（CSV）入库；大文件与原始答卷不入库。
