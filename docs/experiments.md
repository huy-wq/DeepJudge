## E1 · DeepSeek 输出方差探针（2026-10-26）

**要回答的问题**：同一提示词多次调用，输出是否会产生差异？如果完全确定，多采样（#4）就没有意义。

**设置**

| 项 | 值 |
| --- | --- |
| 模型 | `deepseek-flash`，思考模式开启，`reasoning_effort=high` |
| 评分标准 | 3 个采分点 + 1 个扣分项，满分 10（TCP 三次握手） |
| 采样 | 同一输入连续 5 次，串行 |
| 判定 | 每次原始输出走完整流水线（解析 → 接地 → 算分） |

**结果**

| 答卷 | 5 次的等级 | 总分集合 | 原文是否相同 |
| --- | --- | --- | --- |
| 满分答案 | P1/P2/P3 全为 1.0 | {10.0} | **5/5 不同** |
| 弱答案（只说"发请求、同意、确认"） | 0.5 / 0.5 / 0.0 | {3.5} | 5/5 不同 |
| 模糊答案（过程简略、目的说错） | P1 出现 **0.5 与 1.0**，P2=0.5，P3=0.0 | {3.5, 5.0} | 5/5 不同 |

**结论**

1. **文本层面几乎必然不同**：五次输出没有一次字节相同（长度 435–569），所以"模型是确定性的"这个担心不成立。
2. **判定在清晰题上稳定，在模糊题上会漂**：满分与弱答案五次全部一致；模糊答案里 P1 有一次判为 1.0，导致总分 3.5 → 5.0。
3. **这正是多采样要解决的问题**：五次取中位数会得到 P1=0.5（3 次 0.5、1 次 1.0、1 次 0.5），总分 3.5；同时 P1 的离散度 1.0 会拉低置信度，把这份卷子推向人工复核。
4. **延迟** 3.0–7.5 秒/次（含思考），单份 3 次采样约 10–20 秒。

**局限**

- 单题、单模型、5 次采样，样本量不足以断言"漂移率"；只能证明"漂移确实存在"。
- 三次一致时离散度为 0，不代表判定正确，只代表模型这次不犹豫。

**复现**

```bash
cd backend
python3 scripts/probe_variance.py --rubric /tmp/rubric.json --answer /tmp/answer.txt --runs 5
```
